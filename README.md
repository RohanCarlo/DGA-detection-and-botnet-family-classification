# DGA-detection-and-botnet-family-classification
This project focuses on detecting Domain Generation Algorithms (DGA) and classifying botnet families based on generated domain names. DGAs are techniques used by malware to generate a large number of domain names that can serve as fallback communication channels. By identifying these generated domains, this project aims to effectively spot potential botnets and categorize them into known families.

Features
DGA Detection: Identifies domains generated by DGAs, distinguishing them from legitimate domain names.
Botnet Family Classification: Classifies detected DGA domains into various botnet families for better response and mitigation.
Feature Engineering: Extracts relevant features from domain names (e.g., character ratios, n-grams, and length-based patterns) to improve classification accuracy.
Machine Learning Models: Utilizes machine learning techniques to classify domains and identify botnet patterns with high accuracy.(XGBoost and CNN)
This project also uses Fastapi to run a local webpage for the usage of the tool.
